# NFR-T01 nearby search load test plan

Status: ready for coordination; measurement pending. Run on Özgür's isolated Docker setup. Use the same application SHA, PostgreSQL/PostGIS versions, migrations and index configuration as the review build. Record CPU, memory, model/version of tools, worker count, connection settings, seed revision and request mix without secrets.

1. Provision a disposable staging database and import exactly 10,000 synthetic facilities across realistic Istanbul coordinates with varying open states and known true, known false and unknown amenity/price flags. Verify count and spatial index, then ANALYZE. Use a separate database from the live 432-facility directory. Start the API on loopback and verify a plain nearby and a filtered request both return 200 and valid JSON.
2. Prepare a fixed, reproducible list of at least 10 valid nearby requests across different coordinates, radii and filter combinations. Include open_now, has_disabled_access and is_free with intended result sizes. Rotate over that list using k6 constant-vus with 50 clients. Record the mix. Request only GET /api/v1/toilets/nearby and disable redirect following so unexpected 3xx counts as non-2xx. Use the documented query parameter names. Exclude external AI, map tiles and other endpoints.
3. Run a 60-second warm-up with 50 clients, then a separate 300-second measurement with 50 clients using the same request mix. Use a response check for 2xx and a zero-failure threshold on that check during measurement. Collect the total count and status distribution, average and p95 request duration, failure count, throughput and host/DB resources. Use http_req_duration thresholds avg<250 and p(95)<250, with units in milliseconds.
4. Pass only when both latency limits hold and there are zero unexpected non-2xx responses. Keep failed runs and retests separately. Store the seed recipe, script and tool version, both commands, measurement summary, raw redacted data and any environment deviation under evidence/nfr. Confirm the target is isolated before applying load.
